# Avatar image

Place your portrait here as **`avatar.jpg`** or **`avatar.png`**.

- Shoulders-up, clear face and mouth, good lighting.
- LemonSlice outputs ~368×560 portrait video; center crop is applied automatically.
- Override path with `AGENT_IMAGE_PATH` in `agent/.env.local`.

Until you add a file, copy a sample:

```bash
curl -L -o avatar.jpg "https://iili.io/frL9tuj.png"
```

(replace with your own photo for production demos)
